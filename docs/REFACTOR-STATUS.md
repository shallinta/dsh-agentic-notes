## 实现范围

- TaskEvent、Attempt 与 Surface 分离建模，术语见 [CONTEXT.md](./CONTEXT.md)。
- 普通通知、快捷记录、归档、两种 Agent 引擎和 MCP 采用同一持久化队列。
- 最新三条按有效更新时间排序；较早项保留，前项移除后自然露出，无全量入口。
- 执行中关闭仅隐藏，下次有效内容更新重现；等待回答/确认时关闭放弃任务；终态关闭移除。取消任务独立操作，卡片不响应 Escape。
- 支持大小卡切换与唯一大卡；点击回复放大聚焦；草稿保留；按实际同栈卡片高度预留空间。
- 终态小卡默认 60 秒，范围 3—600；悬停、回复草稿暂停，大卡不自动消失，非终态不超时。
- 对齐事件阶段、确认、取消、重试、追问、写入前守卫和持久化恢复。动作保存描述数据，不保存函数回调。
- MCP 返回 Surface ID、事件 ID、执行尝试；支持重复请求去重和旧执行隔离。Tools、Skill、README、SPEC 和 0.3.0 变更记录已同步。
- 每日本地日期首次打开检查已安装 Skill 的内容哈希；不同才提示，用户点击后直接覆盖，不备份。提示文案不绑定具体功能。
- 设置管理弹窗和到期提醒卡片不纳入本次统一。
