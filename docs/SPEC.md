# 随记（dsh-agentic-notes）规格

DSH 插件：左侧栏「随记」入口，中间主区一个笔记本应用。日记 + 主题笔记本；顶部快捷记录；右下角提示卡；首页便笺与待办。

## 一、数据位置

首次打开插件，选一个本地目录作为根。根路径存 `~/.dsh/dsh-agentic-notes.json`，与笔记数据分离。

```
<根>/
  日记/
    2026-11-04.md          # 滚动文档，按开始日期命名
    2026-12-18.md          # 上一册满 5000 行后，下一天开新册
  咖啡/
    手冲参数.md
    豆子记录.md
  工作/
    ...
  便笺/
    2026-11-04-0130.md     # 一张临时便笺一个文件
  todo.json                # 待办卡数据
  agent-logs/              # agent 运行日志；失败保留，成功删除
  .dsh-notebooks.json      # 笔记本清单、便笺位置、归档记录、队列
  .dsh-notebooks/          # 隐藏目录：备份、废纸篓、会话、待审阅操作
    backup/
    trash/
    covers/
    backgrounds/
    sounds/
    agent-sessions/
    agent-pending/
    agent-runs/
    uploads/
```

笔记目录里除 `.dsh-notebooks.json`、`.dsh-notebooks/` 和可见的 `agent-logs/` 外不写别的管理文件。

## 二、日记

滚动文档，倒序：

```md
# 2026年

## 2026年11月

### 2026.11.04 星期三

- 09:14 明天把豆子换成浅烘 → [咖啡 · 手冲参数](../咖啡/手冲参数.md)
- 08:02 早上跑了五公里
```

- 每个标题下面空一行。
- 日期越新越靠上；一天的 bullet 也按时间倒序，新记录插在当天标题下方。
- 两册之间按开始日期命名，不重复；一册记到约 5000 行时，当天写完，下一天开新册。阈值写死，不做配置。
- 日记不写 frontmeta。
- 日历点某天：打开对应文档，滚到那天的三级标题；往下看更早，往上看更晚。

## 三、笔记

- 标题即文件名。新建默认「未命名笔记」，重名加 `-2`，非法字符替换，最长 60 字。
- 改标题同步改文件名，并替换日记里指向它的链接。
- 模型自动创建的笔记由模型命名；每次自动更新时，模型可以建议改名，应用后提示卡给「撤销」。
- 除日记外，每篇笔记顶部有 frontmeta：

```yaml
---
tags: [咖啡, 手冲]
summary: 一句话概括
updated: 2026-11-04T09:20:00+08:00
---
```

- 模型每次归档后检查并更新 tags、summary；`updated` 由插件写。
- 手动新建的笔记，插件只写 `updated`，tags 和 summary 等模型下次归档时补。

## 四、快捷记录

顶部常驻输入框。Enter 保存，Shift+Enter 换行；粘贴多行算一条。

保存顺序：

1. 立即写入当天日记，bullet 以时间为前缀，插在当天最上面。
2. 异步跑归档。可感知的状态挂在 bullet 上：归档中 / 待确认 / 已归档 / 失败。
3. 直接执行小改动，或取得必要确认后写入目标笔记，并在 bullet 末尾追加相对链接：`→ [咖啡 · 手冲参数](../咖啡/手冲参数.md)`。只跳到笔记，不做行定位。

右下角提示卡：

- 每条快捷记录对应一个 TaskEvent 和一个 Surface。从记录日记、排队、归档、问询到终态只更新同一卡片。
- 所有任务提示统一为右下角卡片；需要问答或审阅时放大，不使用中央遮罩。
- 只有必要的用户确认才等待；短记录追加到长笔记不因目标长度单独触发确认。
- 完成后提供查看、调整归属等动作；失败说明日记是否已保存并提供重试。
- 执行中的关闭仅暂时隐藏，下一次有效内容更新重新显示；等待回答或确认时关闭表示放弃本次任务。
- 终态小卡片默认 60 秒后移除，可设置 3—600 秒；悬停、填写回复时暂停，大尺寸卡片不自动移除，非终态无自动超时。

## 五、归档

归档使用 profile 默认模型，先分类，再生成一组操作。

第一步：读取当前笔记本结构、目标笔记标题和 frontmeta，选出目标笔记本和笔记；都不合适时新建。归入已有笔记本时，模型可以顺带给出更新后的描述和关键词：记录带来新主题，或该笔记本的描述/关键词为空时，会补全。分类没有给、且目标笔记本描述或关键词仍为空时，宿主再单独问一次模型补全。关键词取并集，描述只在非空且不同时替换。

第二步：读取目标笔记，生成追加内容、tags、summary，必要时生成整篇改写。操作写进 capture pending，但小改动直接落盘：输入达到 500 字、整篇改写长笔记，或模型依据维护规则请求用户同意时进入待确认；短记录纯追加不因目标笔记很长而要求确认。

第三步：确认后（或小改动自动执行时），一次性应用：

- 新建或改写目标笔记
- 追加带稳定 marker 的 bullet
- 移动或复制相关图片
- 更新 frontmeta
- 更新日记链接和 capture 记录

取消或失败时不写笔记；已复制图片会回滚。成功写入后支持整批复盘撤销。长任务按模型能力分多轮；达到轮次上限时询问是否继续。

所有模型调用均不设置插件自有的输出 token 配额；页面正文、历史、辅助资料、工具结果和模型生成字段不再按隐藏数量阈值裁剪。实际模型容量由服务商配置决定。整合失败后可改为仅追加、不返回整篇改写，但不降低输出预算。服务商仍报告截断时，不解析或写入残缺计划；已保存日记保留，用户重试复用原记录和 Surface，不重复写日记。

设置页的工具结果、网页正文、笔记读取字符上限默认均为 0（不限）。显式设为非零时才执行，并在返回资料中标明截断。安全保护、公开的执行轮次、业务确认与显示预览另行区分，见[模型输入输出边界审计](./MODEL-IO-AUDIT.md)。

## 六、修改归属

提示卡或日记记录上的「调整归属」在同一张大卡片内完成两级选择：

- 选到笔记本即可，由模型在该本里重新挑笔记。
- 也可以展开两级，直接指定笔记或新建笔记。

确认后把那条 bullet 从旧笔记搬到新笔记，更新日记链接与归档记录。旧笔记为空、旧笔记本为空时挪进废纸篓（可恢复）。

## 七、页面

### 首页

- 最顶部是随记标题、刷新、设置和隐私模式等入口。下面是一条常驻的快捷输入：默认一行，聚焦展开三行，失焦收回一行；按钮「记上」。回车保存，Shift+回车换行。输入 `/` 弹出命令列表（memo/todo/note/agent），可打字过滤，上下键移动、空格或回车选中；命令名打全后列表收起。
- 笔记本做成小书本卡片，书名和简介贴在封面底部；没有封面图时用按名字固定的低饱和纯色底。日记固定第一张。
- 首页可以有浅透明背景图，默认不设，设置里上传。
- 右上角深色「待办」入口，吸顶悬浮：始终显示「待办」，有未完成项时带红色角标（超过 99 显示 99+）。
- 首页可以新建便笺；便笺铺在整页，可拖动、八向缩放，不在首页最小化。

### 笔记本

- 笔记目录按最后修改时间倒序，显示标题、修改时间、首行摘要。
- 顶部「新建笔记」。
- 笔记本有名称、描述、关键词和两条维护规则：`agentRules`（Agent 自动更新，`/agent` 可在操作时沉淀，用户也可手改）与 `manualRules`（仅人工，`/agent` 与 MCP 只读）。`/agent` 与 MCP 每次操作该笔记本前都要先读取这两条规则并遵守。
- `/agent` 与 MCP 都能修改名称、描述、关键词和 `agentRules`；`manualRules` 只走 UI 的 `notebook.update`。
- 归档分类同样要读两条规则并遵守（冲突时以 `manualRules` 为准）。最合适的笔记本被规则挡住时，按规则允许的方式处理：改选其他合适笔记本、新建一本、或采用规则允许的写法；需要用户参与时返回 `needsPermission`（ReAct 模式用 `ask_user`）请用户确认。宿主按模型的判断决定是否停下，不按「有没有规则」一刀切。

- `/agent` 或 MCP 以整本/多本笔记本为目标处理完（不是只改单篇笔记）后，会跑一次「经验沉淀」：把这次可复用的操作约定合并进相关笔记本的 `agentRules`，单篇笔记内的修改不触发。每轮最多一次模型调用，输出只有「下次怎么做」，不写流水账；与 `manualRules` 冲突的内容一律丢弃。

### 日历（日记）

- 月历；左右切月；「回到今天」。
- 单月 / 双月切换，双月默认上月 + 本月，并排两列，左早右新，切月两列一起动。
- 有笔记的日期只高亮日期数字。没有笔记的日期不能打开，今天例外：打开空白页，写第一个字才落盘。
- 点日期打开文档并滚到当天标题。

### 笔记阅读 / 编辑

- 默认只读，按 GFM 常用集渲染：标题、段落、粗斜体、删除线、行内代码、代码块（不高亮）、引用、列表、任务列表、表格、水平线、链接、本地图片。不渲染原始 HTML。
- 右上角切到纯文本编辑（textarea）。
- 编辑停手 800ms 自动存，切走强制存，显示保存中 / 已保存。
- 外部改了文件：保存时用修改时间检查冲突；正开着编辑且有未存内容时，顶部冲突条让你选保留本地或载入磁盘。当前没有实时文件监听。

## 八、便笺

- 一张便笺一个文件，`便笺/YYYY-MM-DD-HHmm.md`。
- 首页整页自由拖动、八向缩放；位置尺寸存清单。首页便笺固定在可视区（不随页面滚动），首页也可以直接新建便笺。
- 非首页：右边缘一个「新建便笺」FAB，可上下拖动改变位置；一次页面会话最多建一张，建完跟着当前页面，可以收起成右侧小球，再点开还原；切走就变成首页的一张普通便笺。不绑定页面，回到那页仍是新建入口。
- 空便笺不自动删除，避免切页时误删刚写的内容；可手动删除。
- 便笺正文是一整块自由文本：点击进入编辑，一个 textarea 承载全部内容，可全选、可换行；展示时以 `- `、`* `、`+ ` 开头的行渲染成列表项（圆点 + 悬挂对齐），其余行按普通文本自动换行。
- 悬停时背景渐变为不透明；固定的便笺始终不透明。
- 固定的便笺在二级页面右下角显示，二级页面新建的便笺也在同一个位置。

## 九、待办

- 固定在首页右上角。
- 一条都没有、或有内容但全部勾完，都收成小球；右上角有隐藏已完成项的按钮。
- 新待办排最上面，按创建时间倒序；每条显示创建日期，可打标签。
- 标签自由输入（`#` 触发），可多选；点标签筛选，颜色按文本哈希。
- 存 `便笺/todo.json`。

## 十、agent 会话

- 每轮会话记录输入、助手的提问和选项、用户的选择或回复、助手的最终回复，以及这一轮全部工具调用（名称、目标、成功与否），不裁掉第 40 条之后的记录。
- 会话列表显示首轮输入作为标题、最后一条消息作为预览；详情按轮展开完整的对话。每次打开会话列表都会重新拉取当前会话内容。
- 用户发出的回复先在会话记录里本地回显（状态 running），服务端保存后由刷新覆盖。
- 从 surface 或结果提示里「回复」、选择选项，都续接同一个会话（服务端 `agent.reply` / `agent.answer`），不新建会话。
- 改动基线按类别记录，比对时只看这次操作会碰到的笔记、待办、设置；后台归档或定时提醒写别处不会误判成冲突。

## 十一、其它

- 删笔记本、删笔记进 `.dsh-notebooks/trash/`，提示卡可撤销；日记笔记本不可删。
- 笔记本封面图存 `.dsh-notebooks/covers/`，进入笔记本后作为浅透明背景。
- 设置页：根目录、首页背景图、归档模型和模型服务、自动归档、日历默认单/双月、废纸篓保留天数、隐私模式、提醒声音/朗读及音量、便笺和待办透明度、视觉放大（100%/125%/150%/175%/200%，整页缩放）、终态提示保留时间（3—600 秒，默认 60）、ReAct 轮次、工具结果/网页正文/单次读取长度、网页抓取超时、agent 日志保留与清理、是否显示 agent 会话入口、Agent 引擎（JSON / native 实验）。
- 插件显示名「随记」，包名 `@suiji-ai/dsh-agentic-notes`；左侧栏一个图标入口，主区一个页面。
- 界面目前为中文。
- 归档队列串行执行，避免同时改同一篇笔记。

## 十二、MCP HTTP

- 插件启动时生成随机 `mcpToken`，保存在全局配置。
- 地址固定为 `/dsh-agentic-notes/mcp`。
- 只接受 Bearer token；无 token 返回 401。
- 有 Origin 时只允许 `127.0.0.1` / `localhost`。
- 支持 `initialize`、`ping`、`tools/list`、`tools/call`。
- 工具：list_notebooks、list_notes、search_notes、read_note、read_todo、read_stickies，以及 create_note、write_note、rename_note、move_note、delete_note、update_frontmatter、update_notebook、reorder_notes、reorder_notebooks、todo_*、memo_*。
- MCP 写入直接落盘。
- 设置读写不通过 MCP 暴露。
- 设置页显示地址、Token，可显示、复制、重新生成。
- stdio `mcp-server.js` 与 HTTP 共用 `mcp-core.js`。

## 十三、第一版范围

一次做全：首页、笔记本、日历、阅读/编辑、快捷记录与归档、链接、便笺、待办、设置、废纸篓、冲突处理。

## 十四、写死的默认值

- 日记一册 5000 行。
- 笔记标题最长 60 字。
- 自动保存延迟 800ms。
- 连续归档失败 5 次停下。
- 废纸篓保留 30 天。
- ReAct 默认最多 20 轮，可在设置中调整 1–50。
- agent 日志默认保留 7 天，每 30 天自动清理一次。
- Agent 引擎默认 `native`，`json` 作为兼容回退。
- 结果提示默认保留 10 分钟。

## 十五、统一任务提示

### 模型与模块

- 术语见 [CONTEXT.md](./CONTEXT.md)。TaskEvent 保存任务目标、来源、阶段、会话和执行尝试；Surface 保存内容、交互、队列成员关系和展示状态。
- event-model.js 管状态转换；surface-store.js 管调度；surface-persistence.js 管短文件事务；task-surfaces.js 是任务 Adapter；surface-controller.js 分发用户动作；surface-recovery.js 导入旧等待事项；surface-tools.js 声明外部工具；skill-update.js 检查和安装 Skill。
- 任务通知不再有独立 toast 数组或任务 Modal。设置/管理 Modal、到期提醒卡片保持原有机制。

### 队列和展示

- 队列按最后有效内容更新时间及递增序号排序，最新三条在右下角由下向上展示。较早卡片仍留在队列，移除前面卡片后自然露出，不提供全量提示入口。
- 同内容更新、轮询、心跳、尺寸和草稿变化不改变队列排序。
- 用户可在右上角切换大小尺寸；同一时间只有一张大卡片。放大其他卡片时原大卡自动收缩，草稿保留。
- 小卡不显示回复框；点击回复后放大、展开输入并聚焦。程序放大不抢其他输入框的焦点。
- 关闭按钮始终位于右下角；任务卡不监听 Escape。

### 关闭与过期

- 排队/执行中关闭：暂时隐藏但不取消；下一次有效内容更新使用原 ID 重新进入队列。
- 取消任务是独立按钮，取消向执行器传递，并在写入前检查。已完成的写入保留，不假装回滚。
- 等待回答/确认时关闭：放弃任务，原卡变为取消终态，再按设置移除。
- 终态关闭或过期：从活动队列移除，保留阻止旧响应重放所需的最小记录。
- 所有终态小卡统一使用 surfaceRetentionSeconds，范围 3—600，默认 60。大尺寸、悬停和回复草稿暂停计时。刷新不重置剩余时间，断连后失效的悬停租约不会永久暂停。
- 有效卡片中的明确重试/追问开启新执行尝试、复用 Surface；已移除实例只为新的明确请求创建新卡片，原会话不变。旧尝试的响应不能覆盖当前尝试。

### 存储与恢复

- 宿主的 .dsh-notebooks/surface-queue.json 是队列权威状态，按笔记库隔离；前端只保存投影，不再用 localStorage 重建第二套提示。
- 动作保存类型和参数，不保存 JavaScript 回调。回答绑定当前 interaction ID，确认、撤销、重试防止重复执行。
- 切出随记不取消任务；切回读取实际状态，不重播所有过程。刷新恢复有效按钮、草稿、尺寸和到期时间。
- 旧等待审阅/Agent 问题可以导入；失去执行器或内存等待器的任务标为中断，供用户检查和重试。关闭、过期和旧的已完成结果不重播。

### Tools、MCP 与 Skill

- 内部 Agent 在启动时取得绑定 Surface，create_surface/update_surface 更新同一实例；awaitResponse 结束当前轮等待用户。两种引擎采用相同的卡片状态和用户动作语义。
- MCP 提供 create_surface、update_surface、get_surface、list_surfaces、close_surface；业务工具接受 surfaceId/requestId，返回实际采用的 surfaceId、eventId、attempt。
- 多步外部任务先创建 running Surface，每步继续携带 ID，最后明确提交 succeeded 或 failed。只读工具不持久化完整结果作为重放缓存；写请求用 requestId 和内容指纹防止重放。
- 卡片 ID 不授予授权。用户确认入口仅供界面，模型/MCP 不能替用户批准写入。Skill 仍要求写入前展示方案并等待明确确认。
- 本地日期每天首次打开时，对比已安装与插件附带 Skill 的内容哈希；未安装或一致则静默，不一致创建通用更新提示，同日不重复。
- 用户点击安装更新后直接覆盖并校验，不自动安装、不备份。提示文案不绑定任何具体功能变化。
