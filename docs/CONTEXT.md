# 随记任务提示

任务提示伴随记录、归档、笔记整理和外部调用，说明进展并承接用户的选择。设置管理界面和到期提醒通知不属于本上下文。

## Language

**TaskEvent（任务事件）**：一次有明确目标的处理线索，包含排队、执行、用户参与和执行结果。重试或继续处理是该线索的一次新执行尝试。
_Avoid_：用卡片是否可见判断任务是否结束。

**Attempt（执行尝试）**：事件的一次执行过程。旧尝试结束后产生的进度不能覆盖新尝试。

**Surface（提示卡片）**：事件面向用户的交互载体。正文、尺寸和可见性可以变化，事件未结束时仍是同一个实例。
_Avoid_：toast、modal 作为任务提示的独立类型。

**Queue（提示队列）**：尚未移除、且没有被暂时隐藏的提示集合。展示最新三条不等于删除较早提示。

**Hidden（暂时隐藏）**：用户暂时收起执行中的提示，任务继续；下一次有效内容更新使同一提示重新进入队列。
_Avoid_：取消、结束。

**Terminal（终态）**：本次执行已经成功、失败或取消。纯通知也属于终态，卡片可以继续保留供用户阅读和操作。

**Removed（移除）**：终态提示被关闭或过期后退出活动队列。旧执行结果不能将它重新显示。

**Interaction（用户交互）**：一份明确的问题或写入方案及其对应回答。用户回答只能作用于当时展示的交互，不能批准后来的方案。
